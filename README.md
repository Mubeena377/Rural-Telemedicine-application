**Rural Telemedicine Platform**

Contributors: @Mubeena377, @TeammateHandle,  @TeammateHandle

A Flutter mobile application that lets rural patients consult doctors by video, receive digital prescriptions, order medicines, keep a health record, and call for emergency help, backed by a Flask API and a PostgreSQL database.

1.** Overview & Problem Statement**
The Challenge:
People in rural areas often live far from doctors and hospitals. A simple consultation can mean hours of travel, lost wages and long waiting times.
In an emergency, help does not know where the patient is, and the patient may not know whether the symptoms are serious.
Paper prescriptions and medical history get lost, which makes follow-up care harder.
Getting prescribed medicines delivered is difficult without a local pharmacy.
Target Audience:
Patients in rural and remote areas who have a smartphone and a mobile or Wi-Fi connection.
Doctors who consult patients remotely.
Future roles (already present in the database design): hospitals and ambulance services.

2.** Architecture & Solution Logic**
Concept: A Flutter app with separate patient and doctor interfaces talks to a Flask REST API. The API stores data in PostgreSQL, issues Agora video-call tokens, runs a machine-learning triage model, and sends push notifications through Firebase Cloud Messaging.

Consultation flow
The patient registers or logs in with a phone number and OTP.
The patient describes symptoms. The triage model classifies them as Emergency, Consultation or Basic Care.
The patient books an appointment with a doctor (online, offline, voice or chat).
The doctor starts the video call. The server records a notice and sends a push notification to the patient: "Your doctor is ready".
The patient taps the notification and joins the same Agora channel (named after the appointment).
The doctor saves the consultation notes and issues a digitally signed prescription.
The patient views or shares the prescription as a PDF, and orders the medicines from it within 7 days.
The consultation and prescription become part of the patient's health record.

Getting Started
Prerequisites
Flutter SDK and Android Studio (or VS Code)
Python 3 and PostgreSQL
An Agora account (App ID and certificate)
A Firebase project (for push notifications)
1. Database
Create a PostgreSQL database and run your schema script to create the tables (users, patients, doctors, appointments, consultations, prescriptions, medicine tables, notifications and so on).

2. Backend
bash
cd backend
python -m pip install flask flask-cors psycopg2-binary python-dotenv joblib scikit-learn werkzeug agora-token-builder firebase-admin
Create backend/.env (never commit this file) with:

text
DB_NAME=your_database
DB_USER=your_user
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
AGORA_APP_ID=your_agora_app_id
AGORA_APP_CERTIFICATE=your_agora_certificate
FIREBASE_KEY_PATH=firebase-key.json
Download a Firebase service account key and save it as backend/firebase-key.json (never commit this file). Then run:

bash
python app.py
3. Mobile app
Add your own android/app/google-services.json from the Firebase console.
In lib/api_service.dart, set useRealPhones and computerAddress:
emulator: useRealPhones = false
real phones: useRealPhones = true and your computer's Wi-Fi address
Run:
bash
flutter pub get
flutter run
For real phones, build for the phone chip with flutter build apk --debug --target-platform android-arm64 and install the result on each phone.

**Security Notes**
backend/.env, backend/firebase-key.json and android/app/google-services.json must never be committed to the repository.
This is a prototype: the OTP is a fixed test value, and the API does not yet verify who is calling it. Add real authentication before any real-world use, and check the telemedicine and data-protection rules that apply to you.
