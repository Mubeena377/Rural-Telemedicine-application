# Rural Telemedicine Platform

## About the Project

Rural Telemedicine Platform is a mobile healthcare application designed to help patients access basic healthcare support remotely.

The application provides features such as patient registration, symptom-based triage, emergency SOS support, basic first-aid guidance, medical consultation, and voice-based interaction.

## Features

- Patient registration
- OTP verification
- Emergency SOS
- AI-assisted symptom triage
- Basic first-aid guidance
- Medical consultation
- Medical information upload
- Multilingual support
- Medicine reminders

## Technologies Used

### Frontend
- Flutter
- Dart

### Backend
- Python
- Flask

### Database
- PostgreSQL

### Machine Learning
- Python
- Machine Learning model for triage
